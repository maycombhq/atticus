# Vendor onboarding

## When it applies

Every vendor that receives our data is onboarded before the first call. Northwind Pay was
onboarded for card payments only; any other data sent to it is a new onboarding.

## Card data

Only a card token is sent to NWP; the card number never leaves the shop.

## Northwind Pay products

The Fraud Screen (the Screening API) scores an order and returns a verdict.

## Steps

A security questionnaire, a data processing agreement, then an approval.
