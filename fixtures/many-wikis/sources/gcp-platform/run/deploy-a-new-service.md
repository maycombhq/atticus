# Deploy a new service to Cloud Run

## Steps

1. Ask the Cloud Platform team for a project with the new service request form.
2. Build the service as a container image with the platform's base image.
3. Deploy it to Cloud Run with the platform pipeline, never from a laptop.
4. Give the service its own service account with only the roles it needs.
