Enterprise Architecture : Idempotency Keys

Created by Ana Ruiz, last modified on Jan 10, 2023

Keeping the key

A service that moves money accepts an Idempotency-Key header on every request that changes a payment or a refund.

  • The service keeps each idempotency key for 24 hours.
  • A request repeated with the same key returns the first answer and changes nothing.
