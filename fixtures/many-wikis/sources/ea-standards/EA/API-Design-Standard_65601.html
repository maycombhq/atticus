Enterprise Architecture : API Design Standard

Created by Ana Ruiz, last modified on Jun 18, 2026

Resource naming

  • A REST endpoint names a resource with a plural noun, such as /orders or /refunds.
  • An action on one resource is a sub-resource: POST /orders/{orderId}/refunds, never POST /refundOrder.
  • Path parameters are written in camel case, such as {orderId}.

Versions

A breaking change to an endpoint is a new version of the API, announced to its consumers first.
