Enterprise Architecture : Error Response Format

Created by Ana Ruiz, last modified on Jun 18, 2026

The error body

Every REST endpoint answers an error with an application/problem+json body.

  • The body has the fields type, title, status and detail, and nothing else at the top level.
  • The status field repeats the HTTP status code.
  • The detail field never carries a stack trace or an internal class name.
