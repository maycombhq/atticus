# Real-shaped repos (invented)

Our other fixtures are invented and tidy, and some bugs only show on the shapes real builds, gateways and settings files take. This corpus keeps those shapes. Everything in it is made up: Forge is an invented company, Northwind an invented vendor, every host ends in `.example` or is an in-cluster name of an invented Service. No file is copied from any project: each one is written new, with our names, after the shape of a public, Apache-2.0 open-source project listed below, keeping its structural quirks exactly. So there is no third party's text here and no `NOTICE.md`.

Files are byte-exact (`.gitattributes` keeps `repos/**` out of line-end normalisation): facts cite their line numbers, and three files are CRLF and one starts with a UTF-8 BOM on purpose.

## Facts, estate and expected results

`facts/<repo>.jsonl` is what the assistant writes for each repo, each fact citing its file, line, value and a quote copied from that line, with the other lines it is put together from in `cite.with`. `org-pack/profiles/forge/repos.manifest.yaml` is the estate: the ledger and the gateway list their hosts, the rates service is reached through its Service and Ingress.

- `packages/verify/test/real-shapes.test.ts`: the build-coordinates reader, the settings-path and config checks and the secrets check on these files, and `verifyFacts` on every repo. Every fact here is right, so a correct verifier keeps all of them; those a known bug rejects are listed in the test's `KNOWN` table and are `it.fails`.
- `packages/verify/test/real-shapes-fuzz.test.ts`: seeded property tests for the pom and Gradle readers (indentation, CRLF, BOM, comments, split leaves, attribute and element order, start tags over lines, CDATA, every Gradle notation).
- `packages/core/test/real-shapes-join.test.ts`: the estate join and the dependency join; `expected/join.yaml` and `expected/deps.yaml` are their results, checked by hand (the gateway's proxy chain left out of the golden while two known bugs get it wrong; each is an `it.fails` with the right expectation).
- `packages/core/test/real-shapes-placeholders.test.ts`: seeded property tests for `placeholderIn` and for a placeholder host through the join under each relaxed-binding spelling.

Where today's code gives something other than what a correct reader gives, the test keeps the right expectation and is `it.fails`, with the bug in a one-line `// known bug:` comment above it, so the fix flips it.
