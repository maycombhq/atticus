## CHANGELOG.md (beta.33, Added)

- **Apply pairs what the join left loose (ADR 0210 part 4).** Inside each Apply's write (`atticus verify <repo> --write`, the one build of `verify --all --write`, the app's Apply and CI's), under its lock and before its one build, the calls the estate join left loose go to the model. Only facts an Apply keeps are read (each repo's snapshot, or the write's own facts), never a rejected one. A call's candidates are the other repos' entries that could serve it (`pathProblem`: the same method when both name one; the call's segments the tail of the entry's path, a placeholder matching a placeholder); a call with none is never sent. The calls go in as few requests as `budgets.defaultTokens` allows, none over it (a call alone over it waits for the next Apply), planned as one (`planRun` with N sessions and their summed tokens; no preflight of its own, the write holds the lock). A pairing is drawn only when it cites the call fact's line and the entry fact's line, the paths agree (a segment that differs, as a rewrite, and the prefix left over, as a context path, each on a quoted line it rests on), and every quote is on its line in the checkouts. It is written as ADR 0181's AI pairing (a `link` line by `atticus` with `ai: { runtime: copilot-acp, run }`, one batch), so the write's own build draws it `joined-by-ai` with one undo copy; the rest are dropped and listed. On each Apply every AI line of this pairing not drawn again is checked again on its lines, and withdrawn when one no longer says it ("Withdrew N AI pairings whose lines changed."). Stored per call in `.runs/.pairings.json` (one write an Apply): a call is sent again only when a file its pairing, or its candidates, cites changes; a person's newer line for a call is never sent, moved or overwritten, a line written while the model runs too. The lines after Apply: `Paired 4 calls; 1 left loose.`, what was withdrawn, each pairing dropped with why, each call left loose. With AI off, `apply.pair: off`, no runtime that may decide, inside an assistant's session, or the budget refusing, nothing is sent and the Apply ends as before. Under hand-off Apply pairs nothing (the calls stay loose and the line says so; Connect's Match pairs them). Map › Decided by AI gains Paired by Apply: the last Apply's pairing, drawn, dropped with why, withdrawn and left loose, in the same words as the command line (`PAIR_WORDS`, `COPY.decisions.applyPairs`).
