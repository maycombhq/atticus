# Codebase map

Read this before exploring the repo: it says where things live, so you can open the right files directly. Keep it current when you add a package or move a responsibility.

## Rules of the road

- Contracts (frozen, change only by ADR): `packages/core/src/schema/`: `kinds.ts` (C1 catalog records, schema v2), `dialect.ts` (C2), `review.ts` (C3 rules and findings), `orgpack.ts` (C6), `ai.ts` (C5), `workspace.ts`, `change.ts` and `executors.ts` (C4 files). The local API document is `packages/core/src/api.ts`, written to `docs/api/openapi.json` by `pnpm api:doc`.
- Paths in a metarepo or adopted repo: always resolve with `orgPackDirOf`, `catalogDirOf`, `stateDirOf`, `layoutOf`, `changesDirOf`, `runsDirOf`, `inputsDirOf`, `proposalsDirOf` (and `runsRelOf`, `proposalsRelOf` for messages and stored paths) from `packages/core/src/metarepo.ts`; never `join(root, "org-pack")`, `join(root, ".runs")`, `join(root, "inputs")` or `join(root, "proposals")`. In a repo adopted in place they are all under `.atticus/`.
- Records: parse with `parseRecord`, write with `serializeRecord` (canonical YAML), file path `recordPath` (`<kind>/<id>.yaml`).
- Merge and identity: `packages/core/src/merge.ts` (`mergeCatalog`); curated decisions: `packages/core/src/curated.ts` (`applyCurated`); references: `packages/core/src/refs.ts`.
- The whole scan: `packages/scanner/src/scan.ts` (`scanEstate`: repos, extractors and dialects, merge, intake, features, glossary, federation, curated decisions); catalog files: `packages/scanner/src/files.ts`.
- CLI: `packages/cli/src/main.ts` routes every command to a `*-commands.ts` file in the same folder; tests in `packages/cli/test/`.
- Fixtures (hand-written, byte-exact, never regenerated): `fixtures/forge` (bank-like reference ecosystem; expected catalog `expected/scan.yaml`), `fixtures/forge-change` (the M3 exit change, expected findings and stories), `fixtures/forge-speckit`, `fixtures/forge-dialect-eval`, `fixtures/harbor` (second ecosystem, once merged).
- Decisions: `docs/adr/` (read the one for the area you touch), `docs/build-status.md`, `docs/decisions-pending.md`.

## Where common tasks start

| Task                                   | Start here                                                                                                                                                                                                                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Add an extractor                       | `packages/extractors/src/` (folders `backends/`, `platform/`, `data/`, `speckit/`); register in `src/index.ts` `BUILT_IN_EXTRACTORS`; helpers `src/facts.ts`; readers `src/lang/`, called with `at(repo, path)` or `repo.parseCache` so the scan parses each file once (ADR 0067) |
| Add a dialect                          | `packages/extractors/dialects/` (shipped) or the org pack `dialects/`; engine `packages/extractors/src/dialect.ts`; kit `packages/assistant-kit/kit/`                                                                                                                             |
| Add a CLI command                      | a function in `packages/cli/src/<area>-commands.ts`, routed and listed in HELP in `main.ts`, a test calling the function                                                                                                                                                          |
| Add a critic check                     | `packages/naysayer/src/` (`BUILT_IN_CHECKS`); constitution rules in `packages/naysayer/constitution/`                                                                                                                                                                             |
| Add a knowledge check                  | `packages/knowledge/src/` (`KNOWLEDGE_CHECKS`)                                                                                                                                                                                                                                    |
| Add an outside-system adapter          | `packages/adapters/src/` (interface and mock), manual version in `src/manual/`, registry `src/registry.ts`                                                                                                                                                                        |
| Add an AI agent                        | an agent definition (org pack `agents/` or a built-in default in the package that uses it), context pack via `packages/ai/src/context.ts`, runtime via `createRuntime`, replay recordings under the package `test/fixtures/recordings/`                                           |
| Read a document or diagram             | `packages/ingestors/src/` (`readDocument`, `readDiagram`); intake of `inputs/`: `packages/intake/src/`                                                                                                                                                                            |
| Change lifecycle, hand-offs, approvals | `packages/changes/src/`                                                                                                                                                                                                                                                           |
| Index, query language, impact          | `packages/index/src/`                                                                                                                                                                                                                                                             |
