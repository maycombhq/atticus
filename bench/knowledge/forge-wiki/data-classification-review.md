# Data classification review

## When you need one

Before a new field, column, event attribute or file that holds personal data reaches production, or before personal data is sent to a vendor for the first time.

## How to request it

Raise the Data classification review item in the service desk. The Data Protection Office handles it.

The request needs: each new field with its name and meaning, where it is stored and where it is sent, the proposed level, the retention period, and the business owner.

## Lead time

The Data Protection Office answers within 10 working days.
