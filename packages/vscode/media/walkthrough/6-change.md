# Start a change

**New change** asks what it is and its type, then opens its brief. Write the brief, save it, and run its stages with **Run the next step** in **Next and Waiting**, or in the chat:

- **feature** (`@atticus /feature <change>`): where the change sits among the flows and features;
- **architecture** (`@atticus /architecture <change>`): the target flows;
- **stories** (`@atticus /stories <change>`): the stories and tasks;
- **task** (`@atticus /task <change> <task>`): one task, in Copilot's agent mode with its context.

The critic (`@atticus /critic <change>`) checks every draft. A person approves each stage's pull request.
