# GitHub Copilot

Atticus's AI steps run with Copilot's model, in VS Code. Atticus writes each step's prompt, Copilot answers, and Atticus checks the answer. Nothing goes to any other service.

Set up **GitHub Copilot** and sign in: **Set up Copilot** opens VS Code's own setup (Copilot is built into VS Code 1.143 and later; in an older VS Code it installs GitHub Copilot Chat). The first time a step runs, VS Code asks whether Atticus may use the model: allow it.
