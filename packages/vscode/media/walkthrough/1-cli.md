# The command line

Atticus does its work in its command line, `atticus`; the extension runs it and shows what it finds. It needs Node.js 22.13 or later and Git.

Install it from the offline bundle your team hands out (`atticus-<version>-offline.zip`). Unzip it and run `install.ps1` on Windows, or `install.sh` elsewhere. The install guide has the steps: <https://github.com/maycombhq/atticus/blob/main/docs/guide/install.md>.

Check it runs with `atticus --version` in a new terminal. If it's installed somewhere VS Code doesn't look, set its path in the setting **atticus.path**.
